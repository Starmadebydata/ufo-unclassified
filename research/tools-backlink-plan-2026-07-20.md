# 工具页外链积累方案 — 2026-07-20

目标:为 /tools 各页面(并借此为整个域名)积累真实的、编辑自愿给出的外链。外链既是 6 月核心更新压制后最重要的恢复信号之一,也是不依赖 Google 的持久流量通道。

原则:**每次外联都以对方受众真正想要的东西开路(地图、数字、数据集、追踪器),绝不以"请给我们加个链接"开路。**

## 资产与受众的匹配

| 工具 | 谁会主动链接它 | 一句话卖点 |
|---|---|---|
| /tools/map | Reddit 社区、记者、博主 | "所有可定位的 PURSUE 记录都在一张地图上,并诚实标注精度" |
| /tools/claims | 怀疑论社区、记者、研究者 | "唯一区分'已证实/官方说法/未验证'并附来源的 UAP 主张追踪器" |
| /tools/stats | 赶稿记者、Wikipedia 编辑、AI 引擎 | "可直接引用的数字:207 条记录、8 个机构、逐 Release 拆解" |
| /tools/videos | Reddit、YouTube 创作者、论坛用户 | "85 个已公开视频,一页看全、可筛选" |
| /tools/compare | 研究者、科普作者 | "每个 Release 到底新增了什么——终结'累计数 vs 新增数'的混乱" |

## 第一层级 — Release 周期窗口(杠杆最高,时间敏感)

本站被验证有效的流量通道就是 Release 新闻周期。未来每次发布(Release 05 观察中)都是一个约 72 小时的外链窗口。

1. **参与 r/UFOs megathread。** 每次发布版主都会开集中讨论帖。用工具数据实质性回答真实问题(用 /tools/compare 给逐 Release 数字、用 /tools/map 给地点聚集),链接自然带出。先例:uap.watch 的"我把这批文件重建成了可搜索档案"帖获得大量关注和外链,证明这条路走得通。
2. **一次性的"我做了这个"展示帖**(只发一次,不要每次 Release 都发),在 r/UFOs 和 r/UFOscience 展示地图 + 视频浏览器 + 主张追踪器。措辞要诚实:独立档案站,说清楚它做什么、不主张什么。遵守 Reddit 规则:披露自己是开发者,并在评论区认真互动。
3. **每次 Release 的快速分析文章**(已有的编辑模式)内链工具页——别的站引用分析时,工具链接被一并继承。

## 第二层级 — 可引用数字 PR(稳定滴灌)

4. **Wikipedia。** "United States UFO files" 条目已存在且在活跃编辑中。**不要自己去插链接。** 在条目的 Talk(讨论)页发帖,提议将 /tools/stats 和本档案作为外部资源,并披露利益关系(COI)。Wikipedia 链接是 nofollow,但会带来二次引用——所有经由 Wikipedia 做研究的人都可能引用你。
5. **Release 05 时的记者外联。** 报道每次发布的记者在几小时内就需要逐 Release 数字。给报道过 PURSUE 的几位记者(AP、CBS、NBC、Newsweek、NewsNation、卫报国际版)发简短供数邮件:"逐 Release 拆解、机构构成、目击地图,注明出处即可免费引用",附一张现成的图表图片。
6. **向怀疑论阵地推主张追踪器。** Metabunk 这类社区看重"已证实/未验证"的分类学——主张追踪器是 UFO 站点里罕见的、怀疑论者能够背书的页面。发一个介绍该格式的帖子,欢迎审视,审视本身就带来链接。
7. **专业研究者。** UAP Logbook、The Debrief、The Black Vault 与本站同处一个生态,会链接有用的一手工具。发同行式的简短介绍信,不要求互链。

## 第三层级 — 数据集分发(一次建设,持续复利)

8. **把文档索引发布为开放数据集。** 将目录(207 条记录:编号、标题、机构、日期、Release、地点、文件类型、来源 URL)导出为 CSV/JSON,放进公开 GitHub 仓库,README 中附引用与链接请求。GitHub 仓库本身能被搜索到、被 star、被链接。
9. **上传 Kaggle / data.world**,同一份 CSV,注明规范来源链接。数据新闻从业者和机器学习教程用户会引用数据集出处。
10. **Google Dataset Search** 已覆盖:/tools/stats 页面已内置 Dataset JSON-LD 结构化数据。

## 第四层级 — 站内前置条件(建一次,所有渠道受益)

11. **每个工具页的专属 OG 分享图。** 工具页目前共用默认 OG 图;用地图截图或统计图表做 OG 图,能提升所有渠道的分享点击率。(小型开发任务)
12. **/tools/stats 和 /tools/map 加"引用本页"块** —— 一段可复制粘贴的引用文本(含 URL),复用文档页已有的 citation 块样式,让注明出处零门槛。
13. **/tools/stats 加 CSV 下载按钮** —— 把第 8 项的数据集在站内直接呈现,任何引用这些数字的人都能拉到数据并注明来源。

## 节奏与度量

- **每周(15 分钟)**:查 GSC 链接报告 + Bing 站长工具 / Ahrefs 免费站长版,记录新增引荐域名,标注每条链接是哪个资产带来的。
- **每次 Release**:72 小时内执行第一层级动作。
- **每月**:执行一批第二层级外联(最多 3-5 个联系人,逐一单独撰写,不要模板群发)。
- **红线**:不买链接、不互换链接、不群发邮件、不在多个论坛贴同一份文案——正处于算法压制恢复期,这些行为恰恰会加重我们正在恢复的那类算法评估。

## 成功标准

- **90 天**:新增 10-20 个引荐域名,其中至少 3 个来自专业媒体/研究者层级;开放数据集仓库上线并获得外部 star/fork。
- **关键观察信号**:下一次 Google 核心更新窗口期间 GSC 展示量曲线——外链是那次重新评估的输入之一。
